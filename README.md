# Fraud Detection API

## Overview:

This project is a FastAPI-based REST API for fraud detection. The API utilizes a machine learning pipeline to predict whether a given claim is fraudulent or not.Result: 1 indicates fraud, 0 indicates no fraud.

## Technologies:

Python 3.9
FastAPI
Pandas
Scikit-learn
Pickle

## API Documentation:

FastAPI provides interactive API documentation:
Swagger UI: http://127.0.0.1:8000/docs

## API Endpoints:

Method    |      Endpoint      |      Description
GET              /                    Health check endpoint
POST             /predict             Predict fraudulence of a record
